# Additional research sources

This catalog adds six sources for future exact-ID cross-verification: NeedRoll, Mastercraft, Forever Guide, ItemTree's public Era source compiler, the OpenMap mirror and Questing.wiki. These are research leads, not newly verified runtime rows. `catalog.json` records checked URLs, immutable GitHub pins where available, overlap and the next comparison to perform.

Prioritize independent player observations for Expert Campfire (273101), Sentinel's Boots (251399), Justicar's Boots (251402) and the missing Hyjal vendor recipes. A record's presence in a client table, an addon catalog or multiple copies of the same Classic source does not establish live acquisition.

NeedRoll, Mastercraft and Forever Guide list All Rights Reserved. ItemTree's public repository contains GPL Classic-derived compilers, not the proprietary addon's Forever observation feed. OpenMap's MIT data is mainly client travel data. No restricted addon tables or game art are redistributed here.

For the verified SQL slice, Spyglass and Recipe Registry were used as acquisition references and their MIT notices are retained beside this file. The manifest preserves their pins. Icy Veins' NPC pages supply the numeric loot estimates. Only the relevant factual IDs and rates were transcribed; website prose and assets were not copied. The repository's existing GPL-3.0 terms and Blizzard game-content notice continue to apply.
